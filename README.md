# Machine_learning

📌 Overview

  This project focuses on Supervised Machine Learning, where models are trained using labeled data (input + correct output) to learn patterns and make predictions     on new, unseen data.

  Supervised learning is widely used in prediction, classification, and regression problems such as spam detection, house price prediction, medical diagnosis, and     more.


🧠 What is Supervised Learning?

    In supervised learning:

          We give the model input features (X)
          And correct output labels (Y)

                      𝑋→𝑌

🔍 Types of Supervised Learning

  1️⃣ Classification
       
      Used when output is a category. 
        example 
          yes or no 
          spam or not
   
   2️⃣ Regression
      
      Used when output is a number.
        Examples:
          House price
          salary prediction

📌 Conclusion

    Supervised Machine Learning is the foundation of most real-world AI systems.
    By training on labeled data, models learn to make accurate predictions and decisions.
